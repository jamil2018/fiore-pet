A QUICK HELLO

From download to desktop.

Current builds don't have verified publisher signing. Only approve a download if you trust its source.

On Windows

  1. Run the installer. Download the setup file above and open it.
  2. Review the SmartScreen prompt. If “Windows protected your PC” appears, select More info → Run anyway, if offered and you trust the file. “Unknown publisher” is expected.
  3. Say hello. Finish the per-user installation, open Fiore, and drag your cat to a comfortable spot.

On Mac

  1. Move Fiore into Applications. Open the DMG and copy Fiore.app into your Applications folder.
  2. Try opening it once. If Gatekeeper blocks it and you trust the download, find Fiore in System Settings → Privacy & Security → Open Anyway and confirm.
  3. Set up the reactions you want. Follow the Mac permissions guide for activity, music and optional browser playback.
A note about security. Keep Windows security and Gatekeeper enabled. Managed devices may not offer an exception. These steps are for unsigned-app warnings, not malware or damaged-app alerts. For older macOS settings, checksums and troubleshooting, read the full installation notes.
